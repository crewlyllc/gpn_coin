Network entry

Access points

An access point is a public job API (gpn_scheduler). Hit one URL and the network routes your job to the best idle GPU — no provider addresses needed. They're permissionless and redundant: anyone can run one, so running several is the decentralized front door.

Testnet

Everything below is on the public testnet. Tokens have no monetary value, and the testnet can be reset or change without notice.

Use one from your machine

See the Access the AI page for a working chat example and the full job API. Windows clients need no install — just PowerShell.

Non-loopback POSTs to an access point require Authorization: Bearer <GPN_AP_TOKEN> (or X-Api-Key). Tokens are set per access point and are never published here.

Run your own

Add an access point in one command

Point an access point at the chain and the providers you want it to route to. Expose the port, share the URL, and you're a new front door for the network — no special trust required.

./install-accesspoint.sh
# install + start a systemd --user service:
GPN_INSTALL_SERVICE=1 ./install-accesspoint.sh

gpn-accesspoint-run
Env varMeaningDefault
GPN_LISTENListen address:port0.0.0.0:8092
GPN_ENDPOINTChain RPC endpointws://127.0.0.1:9944
GPN_PROVIDERSComma list of provider /status URLs to route tohttp://127.0.0.1:8093
GPN_SIGNER_URIHot-wallet seed for testnet free-AI mode (creates + escrows jobs)unset (mainnet = client-signed)
GPN_AP_TOKENBearer token required for non-loopback POSTs. Omit it and the first boot generates one (48 hex chars) and prints it oncegenerated on first boot

Config is written to ~/.gpn/accesspoint.env (chmod 600). Secrets stay there — never in a repo or on a webpage. The auth token is generated on the first boot and printed exactly once; retrieve it later with grep GPN_AP_TOKEN ~/.gpn/accesspoint.env and hand it to your callers (./scripts/set-ap-token.sh sets the AP_TOKEN secret on the gpncoin.ai Worker). Full details in the deploy guide and the run-a-node guide.
