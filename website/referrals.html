Referrals

Your code is your wallet, shortened

Every GPN node has exactly one referral code, and nobody types it in. It is computed from the node's payout wallet — the same address block rewards go to — so the same wallet always produces the same code, a different wallet always produces a different one, and anyone can check a code against an address offline. You cannot squat someone else's code without their wallet, and you cannot lose yours unless you lose the wallet.

What one looks like

Thirteen characters: GPN, nine payload characters, one checksum character. The dashes are for reading aloud — the node accepts the code with or without them.

GPN-AX3R-YC7C-KV

That is a real code, from a real address on the dev testnet (5GrwvaEF5zXb26Fz9rcQpDWS57CtERHpNehXCPcNoHGKutQY, the well-known “Alice” account — not a wallet anyone should send value to). It is here so you can watch a code be checked instead of taking our word for it.

How it is derived

Short enough to reimplement from this page. If your implementation disagrees with ours, one of us is wrong and you can tell which.

  1. Take the account id — the 32-byte public key, i.e. your ss58 payout address decoded.
  2. Hash it with a versioned domain — blake2b-256("gpn-referral-v1" ‖ account_id). The domain string means a future scheme can coexist instead of invalidating every code in the wild.
  3. Encode the first 45 bits as base32 — uppercase, no padding, with the ambiguous characters I, O, 0 and 1 removed, so a code read from a screenshot still types cleanly. That is the nine payload characters.
  4. Append a checksum character — blake2b-256("gpn-referral-check-v1" ‖ payload)[0] mod 32 in the same alphabet. A single mistyped character changes it, so a typo is caught on your own machine, not by the network.

Collisions between two wallets are ~2-45. The code carries no information about balances, history or keys — it is a fingerprint, not a key.

Check one yourself

The site's own example, recomputed in twelve lines of Python with no GPN code involved:

import hashlib, base64

ALPHABET = "23456789ABCDEFGHJKLMNPQRSTUVWXYZ"      # Crockford-style: no 0/1/I/O to mistype
def payload(account_id: bytes) -> str:
    d = hashlib.blake2b(b"gpn-referral-v1" + account_id, digest_size=32).digest()
    n = int.from_bytes(d, "big")                            # 256 bits, MSB first
    return "".join(ALPHABET[(n >> (256 - 5 * (i + 1))) & 31] for i in range(9))

def checksum(p: str) -> str:
    d = hashlib.blake2b(b"gpn-referral-check-v1" + p.encode(), digest_size=32).digest()
    return ALPHABET[d[0] & 31]

# Alice's 32-byte account id, then the code
acct = bytes.fromhex("d43593c715fdd31c61141abd04a99fd6822c8558854ccde39a5684e7a56da27d")
p = payload(acct)
print("GPN" + p + checksum(p))        # -> GPNAX3RYC7CKV  (display: GPN-AX3R-YC7C-KV)

Within the node, the same check runs the other way: pasting a code next to an address recomputes the code from the address and compares. A typo is refused with the character it should have been.

Find yours

Four places, all local, none of which needs the network:

  • The dashboard. Start the node with gpn_node --gui and open http://127.0.0.1:8099. There is a Your referral code card with the code and a Copy button. If the machine has no wallet yet, the card says so and names the command that creates one (gpn_node --ensure-wallet) — it never shows a placeholder code.
  • One line at startup. Every start prints referral: GPN-XXXX-XXXX-XX · share https://gpncoin.ai/join?ref=…, so the code is in the log you already read.
  • gpn_node --referral — prints the code, the address it belongs to and the share link, then exits. It opens no port, starts nothing, and needs no chain.
  • Tooling. The dashboard's API answers GET /api/referral with {code, link, address}, or {wallet:false, error} on a machine with no wallet.

What a code is for — and what it is not

It isIt is not
A record of who introduced a node A discount, a payout split, or a reward of any kind — attribution only, and nothing is paid out on the testnet
Write-once per node: the first code a node records is kept A tracking pixel, a cookie, or anything that follows a visitor around the web
Verifiable: a code that does not derive from the presenting node's wallet is recorded as invalid_for_address, not credited Private in the sense of secret — a code points at a public address, so treat it as public information about which wallet you run
Operator-readable: you can see how many nodes came from your code A list of who your referees are, or what they earn

Share it as a link

The canonical form is a join link, not a download link:

https://gpncoin.ai/join?ref=GPN-ZYCU-4W49-6R

A download URL reads as “this will install something” before the person has decided to trust you. /join is a landing page instead: what GPN is, what your code means, and the install commands with your code already in them — with the download behind a button they choose to press.

Pasting a code by hand still works: gpn_node --ref GPN-ZYCU-4W49-6R. Invalid or mistyped codes warn and never block a start.
