Why a proxy?

The testnet access point listens on plain http://…:8092, which a browser on an HTTPS page cannot call. gpncoin.ai/api/* terminates TLS at the edge, rate-limits per IP, and forwards the same request — so your code only ever talks to https://gpncoin.ai.

Copy & paste

Pick your environment

Same request every time — what changes is the quoting. Pasting bash into PowerShell is the usual way this goes wrong, so the samples below are split by environment and each one is written in that environment's own idiom. The testnet ignores the API key, but the OpenAI SDK still requires one: any non-empty string works.

Runs on: PowerShell 5.1+ (shipped with Windows 10 1803+ and Server 2019+). Two traps: curl in PowerShell is an alias for Invoke-WebRequest — you must type curl.exe to get real curl — and line continuations are a backtick, not a backslash.

powershell 
$body = '{"model":"llama3.2:1b","max_tokens":32,"messages":[{"role":"user","content":"What is the capital of Kenya? One word."}]}'

$body | curl.exe -sS --max-time 150 `
  https://gpncoin.ai/api/v1/chat/completions `
  -H "Content-Type: application/json" `
  --data-binary "@-"
powershell · extract the answer 
# uses $body from the block above
$r = $body | curl.exe -sS --max-time 150 `
  https://gpncoin.ai/api/v1/chat/completions `
  -H "Content-Type: application/json" `
  --data-binary "@-" | ConvertFrom-Json

$r.choices[0].message.content

The JSON body goes in on stdin on purpose: it never passes through PowerShell's argument parsing, so no escaping is involved. Inline -d '{"model":"…"}' is the classic failure — Windows PowerShell 5.1 re-quotes the argument and the inner double quotes are lost, so curl receives malformed JSON. If you do need it inline on 5.1, escape as -d '{\"model\":\"llama3.2:1b\"}'; PowerShell 7.3+ passes arguments verbatim instead, so those backslashes must be dropped there. The stdin form above behaves the same on both.

powershell 
$body = @{
  model      = "llama3.2:1b"
  max_tokens = 32
  messages   = @(@{ role = "user"; content = "What is the capital of Kenya? One word." })
} | ConvertTo-Json -Depth 5

$r = Invoke-RestMethod -Uri "https://gpncoin.ai/api/v1/chat/completions" `
  -Method Post `
  -ContentType "application/json" `
  -Body $body `
  -TimeoutSec 150

$r.choices[0].message.content

No quoting to think about — PowerShell serialises the hashtable and parses the reply for you, so the answer is just $r.choices[0].message.content. -TimeoutSec 150 matters: a cold job runs 20–90 s and the default is 100 s. On older Windows 10 builds add [Net.ServicePointManager]::SecurityProtocol = 'Tls12' first if TLS fails.

Runs on: bash or zsh on any Linux distro — curl and a POSIX shell are all you need (jq optional, from your package manager).

bash 
curl -sS --max-time 150 https://gpncoin.ai/api/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "llama3.2:1b",
    "max_tokens": 32,
    "messages": [
      {"role": "user", "content": "What is the capital of Kenya? One word."}
    ]
  }'
bash · just the answer (jq) 
curl -sS --max-time 150 https://gpncoin.ai/api/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"llama3.2:1b","max_tokens":32,"messages":[{"role":"user","content":"What is the capital of Kenya? One word."}]}' \
  | jq -r '.choices[0].message.content'

--max-time 150 covers a cold job (block inclusion + model load). Single quotes are literal in bash/zsh, so the JSON is passed through untouched.

Runs on: the default zsh (or bash 3.2) on any current macOS — curl and Python 3 ship with the OS, so this is copy-paste with nothing to install. jq is the only optional extra (brew install jq).

zsh / bash 
#!/bin/zsh
curl -sS --max-time 150 https://gpncoin.ai/api/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "llama3.2:1b",
    "max_tokens": 32,
    "messages": [
      {"role": "user", "content": "What is the capital of Kenya? One word."}
    ]
  }' \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["choices"][0]["message"]["content"])'

The python3 -c tail pulls out the answer without jq — Python 3 is always present on macOS. Everything else is identical to Linux: backslash continuations, single-quoted JSON.

Runs on: any OS with Python 3.8+ — Windows, Linux and macOS all run this identically. No shell quoting is involved, which makes it the most portable option on this page.

python · requests 
import requests

r = requests.post(
    "https://gpncoin.ai/api/v1/chat/completions",
    json={
        "model": "llama3.2:1b",
        "max_tokens": 32,
        "messages": [{"role": "user",
                      "content": "What is the capital of Kenya? One word."}],
    },
    timeout=150,
)
r.raise_for_status()
print(r.json()["choices"][0]["message"]["content"])

pip install requests. No SDK, no key. timeout=150 covers a cold testnet job; raise it if the network is busy.

python · openai 
# pip install openai
from openai import OpenAI

client = OpenAI(
    base_url="https://gpncoin.ai/api/v1",
    api_key="gpn-testnet",   # required by the SDK; ignored by the testnet
    timeout=150,
)

reply = client.chat.completions.create(
    model="llama3.2:1b",
    max_tokens=32,
    messages=[{"role": "user", "content": "What is the capital of Kenya? One word."}],
)
print(reply.choices[0].message.content)

Any OpenAI-compatible client works: base_url is the only change. The reply object is the same shape — the answer is reply.choices[0].message.content.

Runs on: Node 18+ on any OS (global fetch and AbortSignal.timeout are built in — no npm install), or paste the fetch call into a browser console or Deno/Bun.

javascript 
(async () => {
  const res = await fetch("https://gpncoin.ai/api/v1/chat/completions", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      model: "llama3.2:1b",
      max_tokens: 32,
      messages: [{ role: "user", content: "What is the capital of Kenya? One word." }],
    }),
    signal: AbortSignal.timeout(150_000),
  });

  if (!res.ok) throw new Error(`HTTP ${res.status}: ${await res.text()}`);
  const data = await res.json();
  console.log(data.choices[0].message.content);
})().catch((err) => {
  console.error(err);
  process.exit(1);
});

Save as chat.js and node chat.js. The IIFE means it runs as CommonJS or ESM; AbortSignal.timeout is what stops a hung cold job.

The response shape is the same everywhere 
{
  "id": "chatcmpl-gpn-6238",
  "object": "chat.completion",
  "model": "llama3.2:1b",
  "choices": [
    { "index": 0, "finish_reason": "stop",
      "message": { "role": "assistant", "content": "Nairobi" } }
  ],
  "usage": { "prompt_tokens": 39, "completion_tokens": 3, "total_tokens": 42 }
}

The answer is always choices[0].message.content — data.choices[0].message.content in JS, $r.choices[0].message.content in PowerShell, data["choices"][0]["message"]["content"] in Python.

Capabilities

What you can run today

The job API accepts every GPN work type, but each card below tells you exactly how far that type has actually got. live = running now and reachable from this page; shipped, not wired = the code exists and has completed jobs on the testnet, but there is no public endpoint to call it yet; coming soon = nothing you can call.

💬 Text / LLM live

OpenAI-compatible chat completions on llama3.2:1b and qwen2.5; the model list is whatever the online providers report.

POST /api/v1/chat/completions
{"model": "llama3.2:1b",
 "messages": [{"role": "user", "content": "Hi"}]}
→ {"choices": [{"message": {"role": "assistant",
     "content": "Hi."}, "finish_reason": "stop"}],
   "usage": {"prompt_tokens": 32, "completion_tokens": 3}}

🎨 Image generation shipped · not wired

Real, and proven: gpn_diffusion_provider (diffusers) renders the PNG, commits its sha256 on-chain and serves the artifact from /job/<id>/artifact. Jobs of 512×512 sd-turbo have completed with the artifact hash matching the on-chain result_hash exactly. What is missing is the public path: the access point exposes no /v1/images/generations route (it answers {"error":"not found"}), so images are only reachable through the signed job API below — not from a web page.

POST /jobs          (signed job API, not public)
{"job_type": "ImageGeneration", "model": "sd-turbo",
 "prompt": "a cozy cabin at dusk",
 "width": 512, "height": 512, "steps": 8, "seed": 7}
→ {"id": 1234, "state": "Queued"}
GET /job/1234/artifact → image/png

🎬 Video generation coming soon

The same provider path knows how to run VideoGeneration (LTX-Video through gpn_diffuse.py, with frames/fps parameters), but no video job has ever completed end-to-end: the T5-XXL text encoder needs more VRAM than the 8 GB cards on the testnet have. Treat video as unproven.

POST /jobs          (signed job API, not public)
{"job_type": "VideoGeneration", "model": "Lightricks/LTX-Video",
 "prompt": "waves at sunset", "width": 256, "height": 256,
 "frames": 16, "fps": 8, "steps": 30}

🧮 ML inference coming soon

An MLInference job type and an ML provider binary exist, with a JSON input/output contract, but there is no ML-only endpoint and no completed job to point at.

POST /jobs
{"job_type": "MLInference", "model": "resnet50",
 "input": {"url": "https://…/cat.jpg"}}

🎛️ Fine-tuning shipped · not wired

LoRA fine-tunes have completed on the testnet: a finished tune is served back as model tuned-<jobid> (one is in the live model list now). Same gap as images — no public endpoint, only the signed job API, so there is no click-to-run path here.

POST /jobs          (signed job API, not public)
{"job_type": "FineTuning", "model": "llama3.2:1b",
 "dataset": [{"prompt": "…", "completion": "…"}], "epochs": 1}
→ serves as model "tuned-1234"

Endpoints

All of these are HTTPS on gpncoin.ai and proxy to the live access point. Status codes and JSON bodies are passed through unchanged.

Method & pathWhat it doesLimit
POST /api/v1/chat/completionsOpenAI-compatible chat. Accepts messages[] or a top-level prompt/input.12 calls / 10 min per IP · 64 KB body
GET /api/v1/modelsModel list in OpenAI {"object":"list"} shape.120 / min per IP
GET /api/healthAccess point liveness and provider count.120 / min per IP
GET /api/jobs/<id>On-chain state of a job (Pending, Running, Completed…).120 / min per IP
GET /api/providersLive provider registry: models, capabilities, latency.120 / min per IP
GET /api/modeWhether this AP is testnet (free AI) or mainnet (client-signed).120 / min per IP
Free, but not unmetered

The testnet access point pays escrow from a hot wallet, so a call costs you nothing. Each call is still one GPU job — hence the per-IP cap. For volume, run your own access point or provider node.

Testnet caveats

Prompts and answers are not private (the AP and provider see them; results are stored off-chain). Models are small. No uptime promise — the network is a testnet.
