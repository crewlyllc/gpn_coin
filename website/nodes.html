How to join

Run a node and it shows up here
  1. Download the client for Linux, macOS, or Windows from the download page.
  2. Start it with one of the installers — mining begins by default and the node serves AI work when a job arrives. Steps are in run a node.
  3. Become dialable. Open the P2P port (default 30333, or whatever listen_addr you set) so other peers can reach you; a node behind NAT is still a client, but it cannot be listed as a seed.
  4. Get discovered. A healthy provider registered with an access point is published in this directory automatically, usually within one TTL (60 s).

Machine-readable

The same data, without the HTML

Point a node at the directory and it bootstraps from the whole list — seeds plus live providers — instead of a hardcoded address:

GPN_BOOTNODES_URL=https://gpncoin.ai/seeds.json gpn-node

Endpoints (all CORS-enabled, cached for 60 s):

GET https://gpncoin.ai/api/network     # live: peer ids, providers, counts, offline seeds
GET https://gpncoin.ai/seeds.json      # dial targets (deduped, with a live flag per node)
GET https://gpncoin.ai/bootnodes.txt   # one dialable multiaddr per line

/api/network is the live view behind this page: peer_ids is what system_peers sees, counts has peers_live / serving_ai / offline, and stale: true means the chain read failed — the numbers are then deliberately withheld, not guessed.

The wire format is stable: multiaddrs is always present and is all a simple client needs. nodes adds roles, peer IDs, and provider endpoints; source says whether the AP answered (static+ap) or only the compiled-in seeds were available (static-fallback).
