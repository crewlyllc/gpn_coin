The idea

One GPU, three jobs, always the best one

A GPU is great at two very different things: solving the math that mints coins, and doing the heavy computation that runs AI. GPN treats them as interchangeable jobs and picks the most profitable one in real time.

⛏️

GPU Mining

Ethash-class proof-of-work, ASIC-resistant and GPU-only. Your GPU solves the puzzle and earns freshly-minted GPN as a block reward.

🛡️

GPU-Attested Staking

Stake GPN and prove your GPU is real (attest real GFLOPS) to earn a tiered reward multiplier — Bronze, Silver, or Gold.

🖥️

AI Compute Marketplace

Rent GPU time to run inference or fine-tuning jobs. Escrow-protected payment, verified proof-of-compute, 5% marketplace fee.

📈

Profitability Auto-Switch

A governed on-chain oracle tracks prices and utilization. Each GPU automatically switches mining ↔ compute to whatever pays more per hour.

How to use it

Get on the network in minutes

You don't need any GPN to start mining — mining is how GPN is created. Here's the path from nothing to earning.

1
Set up a wallet

Install the Polkadot.js browser extension and create an account. This is your GPN address.

2
Get test GPN (faucet)

Request a free drip from the faucet — you'll want it for the attestation stake and fees.

3
Run a node + miner

Install the node and GPU miner, then point it at the network. Your GPU starts producing blocks.

4
Stake & attest

Stake 1,000 GPN and prove your GPU's real throughput to unlock the tiered reward bonus.

5
Rent or rent out

Post a compute job in the marketplace, or list your GPU to serve jobs — paid via escrow.

Architecture

Built on the Polkadot SDK

GPN is a standalone Layer-1 blockchain (not a token on another chain). It's built on Substrate, so it gets runtime upgrades, multi-signature support, and a path to post-quantum signatures.

🧩

5 core pallets

gpu-pow (mining), gpu-attestation (staking), compute-marketplace (rental), profitability-oracle (auto-switch feed), gpn-token (coin economy).

🪙

GPN tokenomics

50 GPN/block, 10%→1% inflation decay, 1B supply cap, 5% marketplace fee routed to staking/treasury/burn/oracle.

🔗

RPC + REST API

Talk to the chain via JSON-RPC, or use the REST API for programmatic job creation and account queries.

🧠

Quantum-ready

Uses sr25519 today (like every chain); MultiSignature gives a migration path to post-quantum signatures later.
