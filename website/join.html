Install — pick your machine

Each block below already includes your code. Paste the whole block; nothing needs admin rights.

Windows (PowerShell)

New-Item -ItemType Directory -Force C:\gpn | Out-Null
$m = Invoke-RestMethod https://gpncoin.ai/releases.json
$asset = $m.assets | Where-Object { $_.os -eq 'windows' }
curl.exe -fL -o C:\gpn\gpn-windows.zip $asset.url
if ($LASTEXITCODE -ne 0) { throw "download failed (curl exit $LASTEXITCODE)" }
$f = Get-Item C:\gpn\gpn-windows.zip
if ($f.Length -ne $asset.size) { throw "download is $($f.Length) bytes, manifest says $($asset.size) — refusing to extract" }
if ((Get-FileHash C:\gpn\gpn-windows.zip -Algorithm SHA256).Hash.ToLower() -ne $asset.sha256.ToLower()) { throw "sha256 mismatch — refusing to extract" }
Expand-Archive C:\gpn\gpn-windows.zip -DestinationPath C:\gpn\bin.pending -Force
powershell -NoProfile -ExecutionPolicy Bypass -File C:\gpn\bin.pending\install.ps1

Linux

curl -L -o gpn-linux.tar.gz https://github.com/crewlyllc/gpn_coin/releases/download/linux-latest/gpn-linux.tar.gz
mkdir -p gpn && tar -xzf gpn-linux.tar.gz -C gpn && cd gpn
./install.sh

Windows — manual, from an unzipped bundle

cd C:\gpn
.\bin\gpn_node.exe --setup
.\bin\gpn_node.exe

From a source clone (Linux)

./install.sh
