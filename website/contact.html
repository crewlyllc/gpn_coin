Security

Found a vulnerability? Please don’t open a public issue. Use GitHub’s private security advisory so it can be fixed before it’s public. Reports about the testnet chain, the access point API, or the release/updater path are all in scope.

Never share secrets

Nobody from GPN will ever ask for your seed phrase, keystore, or a private key — not on X, not in Discord, not in a DM. Treat any message that does as an impersonator and report it.
